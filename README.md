# Quizly Quiz Platform

A quiz management platform interface built with React and Vite. The current baseline includes a responsive student dashboard, quiz library cards, progress tracking, activity overview, leaderboard, quiz detail view, and a Student/Admin role switch that reveals admin navigation.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Day-wise delivery

- **Day 1:** React/Vite project setup, environment-ready npm scripts, responsive app shell.
- **Day 2:** UI account identity and role switch foundation. API authentication is planned for the backend phase.
- **Day 3:** Student/Admin navigation states and protected-area UI foundation.
- **Day 4:** Student dashboard, statistics, navigation, and leaderboard panels.
- **Day 5:** Quiz library cards and quiz detail entry flow.
- **Day 6:** Quiz metadata, progress, categories, and question preview foundation.
- **Day 7:** Quiz launch surface with timing and progress context.
- **Days 8-12:** Submission, results, student analytics, admin analytics, and category rankings are the next backend-connected phase.
- **Days 13-14:** Automated tests, production database, deployment configuration, screenshots, and presentation documentation.

## Current scope

This repository is a polished frontend prototype using local demo data. Authentication, persistence, API validation, score calculation, and deployment require a backend/database connection before production use.
